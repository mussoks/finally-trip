# 드디어! (finally-trip)

> 10~20년 일만 하느라 여행 한번 제대로 못 가 본 사람을 위한 여행지 골라주기 앱

여행을 못 간 이유는 돈보다 **고를 힘과 노하우**가 없어서인 경우가 많아요.
그래서 "드디어"는 검색창 대신 몇 가지 질문과 음식 스와이프만으로 여행지를 **대신 골라 주고**, 체력에 맞는 일정까지 짜 줘요.

## 지금 들어 있는 기능 (MVP)

| 화면 | 하는 일 |
| --- | --- |
| 근속 연차 | 몇 년 일했는지 입력하면 근속 기념 뱃지를 만들어 줘요 (출근일·커피 잔 수 대충 계산) |
| 여행 스타일 | 동행(혼자/배우자/아이/부모님), 휴가 길이(2박3일~4박5일), 하루 걸음 수, 국내/해외 |
| 음식 스와이프 | 음식 카드 12장을 좌우로 넘겨 입맛을 골라요. 되돌리기, ← → 키 지원 |
| 추천 결과 | 여행지 15곳의 **입맛 궁합 %**를 계산해 상위 3곳을 카드로, 나머지는 순위 목록으로 보여줘요 |
| 여행지 상세 | 먹을 것 · 볼 것 · 현지인 픽 · 문화 한 스푼 · **체력 맞춤 일정** · 주문 카드 · 여행 팁 |
| 주문 카드 | 현지어 문장을 크게 띄워 점원에게 보여줄 수 있어요 (일본어, 중국어(대만), 베트남어, 태국어, 영어, 제주어) |
| 캡슐 뽑기 | 그래도 못 고르면 가챠 머신으로 운명에 맡겨요. 궁합이 높을수록 잘 나와요 |

선택한 내용은 브라우저 `localStorage`에 저장돼서 새로고침해도 이어서 볼 수 있어요.

## 추천은 이렇게 계산해요

`src/lib/match.js`

1. **입맛 점수**: 스와이프에서 "먹고 싶다"한 음식의 태그(국물, 면, 해산물...)를 모아서, 여행지마다 매겨 둔 태그 가중치(0~3)와 곱해요. 패스한 태그가 강한 곳은 조금 깎아요.
2. **현실 조건**: 휴가가 짧은데 비행이 길면 감점, 필요한 걷기 양이 체력보다 많으면 감점, 부모님과 가면 가까운 곳에 가점을 줘요.
3. 합친 값을 58~99% 범위의 "입맛 궁합"으로 바꿔요.

일정(`src/lib/itinerary.js`)은 체력에 따라 달라져요.

- 하루 5천 보: 매일 오후에 **숙소 낮잠**
- 하루 1만 보: 오후에 쉬는 일정이나 볼거리 하나
- 하루 2만 보: 해질녘 일정까지 하나 더
- 부모님 동반이면 체력을 최대 1만 보로 낮춰서 짜요
- 현지인 픽 가게는 그 가게가 붐비는 끼니(아침/점심/저녁)에 넣어요

## 실행하기

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성
npm run preview  # 빌드 결과 미리보기
```

`vite.config.js`의 `base: './'` 덕분에 `dist/`를 GitHub Pages 같은 하위 경로에 그대로 올려도 돼요.

## 기술 스택

- React 18 + Vite 7
- Tailwind CSS 3 (색은 `src/index.css`의 CSS 변수 토큰, 라이트/다크 모드 모두 지원)
- framer-motion: 스프링 애니메이션, 카드 드래그, 캡슐 머신
- lucide-react 아이콘
- 폰트: Bagel Fat One(제목), IBM Plex Sans KR(본문) — Google Fonts

## 폴더 구조

```
src/
  App.jsx               화면 전환과 상태 저장
  data/
    destinations.js     여행지 15곳 (국내 5, 해외 10)
    foods.js            음식 스와이프 카드 12장과 태그 이름
    prefs.js            동행·기간·체력·지역 선택지
  lib/
    match.js            입맛 궁합 계산, 캡슐 뽑기 가중치
    itinerary.js        체력 맞춤 일정 생성
    storage.js          localStorage, 진동(햅틱)
    pop.js              팝 컬러 클래스 매핑
  components/
    Mascot.jsx          넥타이 풀린 캐리어 캐릭터
    ui.jsx              스티커 버튼, 칩, 뱃지 등
  screens/              Intro, Years, Prefs, Swipe, Results, Detail, Gacha
```

## 주의: 데이터는 샘플이에요

`src/data/destinations.js`는 MVP용으로 직접 큐레이션한 샘플이에요.
이동 시간은 대략적인 직항·KTX 기준이고, 가게 이름 대신 "동네 야타이" 같은 **가게 유형**으로 적어 두었어요.
실서비스 전에는 공식 출처로 확인하고, 아래 데이터 소스로 바꿔야 해요.
